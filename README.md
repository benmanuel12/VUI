# Voice User Interface

This is a 3rd year university project in which I made a voice user interface to help computer science students
It was somewhat hard to test as it was created during Covid, and I could not find a way to give both the code and Zoom access to the speakers and microphone, so that a friend who was assessing the work could speak to me on Zoom, have the interface pick it up, respond on my speakers, and have the computer send that audio back to my friend.

## Built with
JavaScript, Node.js

## Current Features
- Indexes files and tracks h1 and h3 markdown tags
- Allows user to search for tracked tags by voice command
  -  Please do a search/look for "word"
  -  Please find "word" in "other word"
- Functioned as a handsfree way to search through notes in markdown format
